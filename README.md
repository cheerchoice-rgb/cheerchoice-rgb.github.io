# Vocabulary Notebook

A browser app for recording English words while you study: definitions, Chinese explanations, flashcards with spaced repetition, and a quiz.

Open the app: **https://cheerchoice-rgb.github.io/Vocabulary-new/**

## Install as an app

- **Phone (Safari / Chrome):** open the link → Share / menu → Add to Home Screen.
- **Desktop (Chrome / Edge):** open the link → install icon in the address bar.

Words are stored in this device’s browser (`localStorage`). Export JSON or CSV if you want a backup.

## Use locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
